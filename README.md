# 🌙 Hadith Ai.BOT — لوحة التحكم الإدارية

## التعريف

النظام الإداري الشامل لبوت الواتساب الإسلامي **Hadith Ai.BOT** — التابع لمنظمة حديث الإسلامية.

- **المؤسس**: الدكتور طارق الفارس
- **الشركة المطورة**: UNIRAL للتطوير التقني والعلمي وهندسة الذكاء الاصطناعي (تابعة لمنظمة حديث الإسلامية)
- **النموذج (الاسم الظاهر)**: Hadith Ai-1.5 Flash Pro
- **منصة المنظمة**: سِراجًا منيرًا — [siraj-munira.vercel.app](https://siraj-munira.vercel.app)

لوحة تحكم عربية كاملة (RTL) بتصميم إسلامي وقور — مخطوطة ورقية بخط Amiri ولون ذهبي فانوسي — لإدارة كل جوانب البوت.

## الميزات

| القسم | الوصف |
|---|---|
| **نظرة عامة** | إحصائيات حية (مستخدمون، جروبات، رسائل، آيات) + آخر النشاط + إجراءات سريعة |
| **الاتصال** | ربط البوت بواتساب عبر **رمز QR** أو **كود اقتران من 8 خانات** — بكل صيغ أرقام الدول |
| **المستخدمون** | بحث وإدارة، حظر/إلغاء، اشتراك، ومراسلة مباشرة |
| **الجروبات** | طلبات الانضمام المعلقة تنتظر **موافقة المسؤول** قبل تفعيل البوت |
| **البث والرسائل** | محرر بتنسيق واتساب (Markdown) مع معاينة حية + استهداف + سجل البث |
| **المجدولات** | تذكيرات الجمعة + الآيات الدورية + الاقتباسات + أذكار الصباح والمساء |
| **القرآن الكريم** | تلاوة آيات بصوت الشيخ رعد الكردي كرسائل صوتية مرفقة بنص الآية |
| **الذكاء الاصطناعي** | ضبط الرد التلقائي ونبرته + اختبار مباشر للنموذج |
| **الإعدادات** | هوية البوت والمنظمة والروابط الرسمية + التهيئة التقنية |
| **السجلات** | سجل كامل بمستويات (معلومة/تحذير/خطأ) مع فلاتر وتحديث تلقائي |

> **بيانات حقيقية فقط**: عند عدم إمكانية الوصول لسيرفر البوت تعرض اللوحة حالة «البوت غير متصل» بصدق — بلا أي بيانات وهمية. تسجيل الدخول **بكلمة المرور فقط** (بدون اسم مستخدم).

## البنية

```
هذه اللوحة (Next.js — تُستضاف على Vercel)
        │
        │  HTTPS + X-API-Key
        ▼
سيرفر البوت (Node.js — Baileys + Express + SQLite)
   يُشغَّل على: https://hadithbot.wispbyte.org
```

اللوحة **بلا قاعدة بيانات** (stateless): كل البيانات تعيش على سيرفر البوت، والاتصال محمي بمفتاح مشترك.

## متغيرات البيئة (Vercel → Settings → Environment Variables)

كل القيم الافتراضية مطابقة لما هو مضبوط في سيرفر البوت — اللوحة تعمل فورًا حتى بدون إضافة أي متغير. أضفها فقط إذا غيّرت القيم على السيرفر:

| المتغير | الوصف | الافتراضي
|---|---|---|
| `BOT_API_URL` | رابط سيرفر البوت | `https://hadithbot.wispbyte.org` |
| `BOT_API_KEY` | المفتاح المشترك (نفس قيمة البوت) | `hadith_bot_key_2026_uniral` |
| `ADMIN_PASSWORD` | كلمة مرور الدخول (المصدر الوحيد للدخول — لا يوجد اسم مستخدم) | `Hadith@2026` |
| `AUTH_SECRET` | سر توقيع الجلسات — **غيّره لقيمة عشوائية طويلة** | `...` |

> ⚠️ **مهم**: غيّر `ADMIN_PASSWORD` و`AUTH_SECRET` و`BOT_API_KEY` قبل الاستخدام الإنتاجي.

## النشر على Vercel

1. اعمل Fork أو استورد هذا المستودع إلى حسابك.
2. من [vercel.com/new](https://vercel.com/new) اختر المستودع.
3. (اختياري) أضف متغيرات البيئة من الجدول أعلاه — الافتراضيات تعمل فورًا.
4. اضغط **Deploy** — سيكتشف Vercel إطار Next.js تلقائيًا.

## التطوير محليًا

```bash
npm install
npm run dev            # http://localhost:3000 — يعمل بالافتراضيات مباشرة
```

## الأمان

- الجلسة: كوكي httpOnly موقّع بـ HMAC-SHA256 (صلاحية 7 أيام).
- المصادقة على البوت: هيدر `X-API-Key` إلزامي لكل نداء.
- حماية من محاولات الدخول المتكررة (5 محاولات/دقيقة).
- **لا ترفع ملف `.env` أبدًا** — استخدم متغيرات بيئة Vercel.
